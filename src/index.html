The Architecture Behind Intelligent Software.

AI is moving beyond generating answers and code. The next challenge is building systems that can plan, use tools, coordinate workflows, and execute work reliably within real-world constraints.

That is the promise of agentic infrastructure: the connective tissue between AI capability and dependable outcomes.

01 / The concept

From AI demos to dependable systems.

An AI model can reason or generate content. An agent can use that capability to pursue a goal through a sequence of actions. An agentic system connects agents to the tools, data, controls, and operational infrastructure needed to perform useful work.

The distinction matters. A compelling demonstration is not the same as a reliable production system. Reliability depends on architecture, access control, evaluation, observability, and the ability to recover when something goes wrong.

The question is not only what AI can generate. It is what we can reliably build, govern, and operate with it.
02 / The architecture

Six layers. One operating system for action.

There is no single universal agent stack. These six layers are a practical mental model for designing systems that connect intelligence to real work without losing control of security, cost, or quality.

LAYER 01

Intelligence & Models

Choose models based on capability, latency, cost, context needs, and task risk. Combine language and multimodal models where appropriate.

Model routingInference
LAYER 02

Agents & Orchestration

Manage task planning, delegation, state transitions, retries, timeouts, and workflows. Use multi-agent patterns only when they improve outcomes.

PlanningWorkflow state
LAYER 03

Tools & Connectivity

Connect agents to APIs, databases, business applications, and approved external services. Define tool contracts and validate every input and output.

APIsMCP
LAYER 04

Context, Data & Memory

Provide relevant information through retrieval, structured data, and controlled state. Apply data lineage, retention rules, and access-aware retrieval.

RAGState
LAYER 05

Identity, Security & Governance

Apply least-privilege permissions, secrets management, policy checks, audit logs, approval gates, and isolation between users and tenants.

PolicyHuman approval
LAYER 06

Evaluation & Observability

Trace actions, measure task success, test for regressions, monitor cost and latency, detect unsafe behavior, and design for graceful failure.

03 / Enterprise implications

Connect intelligence to the work itself.

Consider a business workflow that gathers information from approved sources, analyzes it, updates a system of record, and prepares a report for human review. The model is only one component. The outcome depends on the entire system.

THE OPPORTUNITY

Move beyond isolated copilots

Connect AI to defined business processes so it can assist with multi-step work, while preserving clear boundaries around sensitive actions and decisions.

THE ENGINEERING CHALLENGE

Make actions inspectable and reversible

Validate inputs, constrain permissions, log decisions and tool calls, test failure paths, and require human approval when risk warrants it.

THE BUSINESS TEST

Measure outcomes, not activity

Track task completion, error rates, cycle time, cost per successful outcome, user acceptance, and the frequency of human intervention.

THE DESIGN PRINCIPLE

Use autonomy deliberately

Start with narrow tasks and explicit limits. Expand autonomy only when evaluation evidence, operational controls, and business value justify it.

04 / A documented prediction

The democratization of software development.

In a Quora answer published in 2018, I argued that basic software development would become increasingly accessible as development platforms improved. I also distinguished that shift from the continued value of deep engineering skills and domain expertise.

As building software becomes easier, the advantage shifts toward knowing what to build, how systems should work, and how to make them secure, reliable, and useful.

NOW

From code generation to system design

AI coding assistants and natural-language development tools are accelerating software creation. The next challenge is not just generating code, but integrating components, validating behavior, managing permissions, and operating systems responsibly.

NEXT

Intelligent systems that take action

As agents become more capable, architecture and governance become increasingly important. The opportunity is to build systems that convert business intent into useful actions with measurable controls and outcomes.
